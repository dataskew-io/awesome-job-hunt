# Awesome Job Hunt

A curated list of platforms, tools, and resources to find data engineering and tech jobs.

## Job Boards & Search Platforms

| Name | Link | Description |
|------|------|-------------|
| LinkedIn | [linkedin.com/jobs](https://www.linkedin.com/jobs/) | The default professional network. Best for networking, referrals, and discovering roles through connections. |
| Welcome to the Jungle | [welcometothejungle.com](https://www.welcometothejungle.com/en) | Tech-focused job board with company culture profiles, salary transparency, and immersive company pages. |
| Hiring Cafe | [hiring.cafe](https://hiring.cafe/) | AI-powered job search that aggregates listings and lets you filter with natural language queries. |
| Jack and Jill AI | [jackandjill.ai](https://www.jackandjill.ai/) | AI job matching platform that connects candidates with roles based on skills and preferences. |
| Welyk | [recruiting.welyk.tech](https://recruiting.welyk.tech/jobs) | Recruiting platform with curated tech job listings and streamlined application flows. |

## Strategy & Career Resources

| Name | Link | Description |
|------|------|-------------|
| Career Ops | [github.com/santifer/career-ops](https://github.com/santifer/career-ops) | Open-source career operations framework. Systems and processes for running a structured, repeatable job search. |
| ResumeAI | [withresumeai.com](https://withresumeai.com/) | Free ATS checker plus State of ATS 2026 (738 employers, 704 portal-verified). |
